# 轨迹 Viewer 搜索验收

日期：2026-10-26。增加浏览器内的主轨迹文本搜索，不新增 API 或修改原始轨迹/对象存储。

搜索覆盖当前已加载投影中的消息、reasoning、工具名称、调用 ID、参数和观察结果，并按步骤过滤。输入只保存在当前页面状态，不写入 URL，也不发送到 Hub。空结果时提供明确提示；可访问标签和实时结果数量供辅助技术读取。

验证：`make check` 通过，142 passed、51 skipped；Python lint/格式、OpenAPI 检查、前端类型检查及 Next.js 生产构建通过。测试运行有一项现有 Starlette/httpx 弃用警告。Runtime 未改变，无需运行 `make runtime-check`。

范围限制：搜索仅覆盖 Hub 已投影且最多 1000 步、原始轨迹不超过现有 1 MiB 预览边界的数据。大文件下载、多模态、子轨迹和统计聚合仍未实现；本变更不构成完整高级 Viewer 验收。
