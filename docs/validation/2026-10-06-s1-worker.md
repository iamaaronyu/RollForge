# S1 Worker 实现与验证记录

日期：2026-10-06。本轮真实主链已在受限 LAN、并发 1、审核合成任务范围通过；Linux 临时策略已恢复并复核，正式执行入口保持关闭。范围：单 Trial 可运行快照、独立固定版本 Runtime 子进程、上传后元数据提交与本地恢复。对象存储实现及真实存储恢复验收由另一开发聊天负责。

## 已实现

- packages/schemas 定义不含凭证的 RunnableBinding，固定 Claude Code 2.1.81、Anthropic Messages、deepseek-flash、网关根地址和 separate verifier；Agent/Model Revision 摘要与绑定强制一致。
- claim 的 runnable_only 过滤元数据 Job；租约返回 job_id。Worker 每次领取一个 Trial，300 秒租约，每 30 秒续租。
- Task 归档摘要及规范内容摘要双校验；拒绝越界路径、链接、特殊文件和超预算归档。
- Runtime 使用独立 Python 和限定环境；Hub/S3 凭证不传给子进程。网关必须匹配 Worker 配置，默认 HTTPS；LAN HTTP 需显式启用。
- 使用实际安装的 Harbor 0.24.0 Trial.create / Trial.run 和 TrialResult；Harbor 负责 Sandbox 生命周期。Worker 取消时发 SIGTERM 并等待 Harbor 清理。
- 原生结果校验和任务不可变复核后才标记可上传；平台不伪造 Harbor 原始结果。
- 对象存储发布 Manifest 后落盘 pending-commit；Hub 在持有租约行锁的事务内验证对象作用域、token、摘要、文件和结果汇总，提交前再次核对数据库时钟。
- --resume 只重试已有产物的上传/提交，不重跑同一 Execution；提交响应丢失可幂等重放。
- OpenAPI 和前端类型重新生成；默认执行开关关闭，platform.execution_enabled 保持 false。

## 本轮真实 Worker 主链验收

使用真实 HTTP Uvicorn Hub、静态 USER/WORKER 分离认证、独立 PostgreSQL 16、真实 MinIO、独立 Harbor 0.24.0 / E2B 2.46.0 Runtime、Claude Code 2.1.81、Mac 受限模型网关和 DeepSeek Anthropic Messages。模型上游 Key 只在 Mac，不复制到 Linux/Sandbox。会话 30 分钟、最多 24 次请求、单次输出最多 8192 token；本轮日志记录 14 次上游 HTTP 200 响应。

| 场景 | 实际结果 |
|---|---|
| 正常真实执行 | reward=1.0，Hub COMPLETED，原始产物上传并由 Hub 从 MinIO 重读验证；耗时 32.32 秒，16 个原始文件 |
| 已接受提交的响应丢失 | HTTP transport 在收到真实 Hub 200 后丢弃响应并抛网络错误；pending-commit 保留，新 SDK/Worker resume 重放为相同 Execution 的 COMPLETED |
| 真实零分 | reward=0.0，Hub COMPLETED，15 个原始文件；耗时 27.56 秒，没有误判基础设施失败 |
| Worker 协作式取消 | 真实 Sandbox 活动期间取消 Worker；SIGTERM 转交 Runtime，Harbor 完成清理，原生结果为 CancelledError、无评分；耗时 11.42 秒，11 个原始文件 |
| 取消后 Retry | 测试数据库注入租约过期，再调用权威回收服务；HTTP 领取同 Trial 的新 Execution，fencing token 从 1 到 2，保持同一快照；同一 Worker 执行路径最终 reward=1.0，耗时 81.15 秒，16 个原始文件 |
| 迟到提交 | 新 Execution 领取后，旧 lease 的完成请求被 HTTP 409 拒绝，不写旧结果 |

过期是本轮专用数据库中的故障注入，没有等待 300 秒墙钟期限；实际数据库时间边界由 PostgreSQL 集成测试另行验证。取消使用协作式取消及 Runtime SIGTERM，不代表 Worker/Runtime SIGKILL 或宿主断电下的 Sandbox 恢复已经通过。

真实 Agent 工具写出的隔离布尔值确认：有受限会话，E2B/Hub/S3 凭证环境缺失，私密 canary 不可见，网关其他监听端口和 Linux 控制地址不可达。独立 Verifier 中私密 canary 可见，模型/E2B/平台凭证环境缺失。对成功、零分和成功 Retry 的原始输出逐字节检查，真实上游 Key、E2B Key、Hub token、S3 凭证及本轮会话 token 均为 0 命中。取消和 Retry 快照 Task digest 相同：sha256:696d8676e62f05e1a4b123781ec9b4edda02cd73304b23a2ecfcf6f874f20f5c。

### 真实运行发现并修复的问题

- Runtime Python 不能使用 Path.resolve：venv 的 python 是符号链接，解析后跳到基础解释器、丢失固定 Harbor/E2B 依赖。改用 absolute 保留选定 venv。新增真实 OS 子进程离线回归，验证实际启动了所选 venv 且没有 Hub/S3 凭证；该回归使用替身 Runtime，不冒充主链验收。
- 固定 SDK 在 Mac 隔离环境下受系统代理影响；只读直接 HTTP 列表返回 200，但不完整代理配置的 SDK 返回 503。显式清空大小写代理变量，NO_PROXY 列出可信端点，保持独立 HOME 和凭证白名单。真实 SDK 读列表及随后完整主链通过；通配符配置未计为通过。
- Linux 准备脚本初次写错部署父目录，在固定文件校验阶段退出，没有修改网络。修正为实际固定版本子目录、核对原 override 摘要并保留原代理配置，owner 再次 prepare 后验证单 /32 网关配置生效。

本轮首次真实执行命令因外部 payload/目的地/预算未明确而被自动审批拒绝，未执行。列出公开合成任务、固定官方 DeepSeek 目的地与预算后，用户要求继续，审批放行；不向模型发送凭证、凭证摘要、内部规划或业务数据。

本轮 make check：140 项通过、0 跳过，Python lint/格式、OpenAPI 同步、前端类型与构建通过；make runtime-check：9 项通过。新增真实 OS 子进程离线回归后 Worker 边界测试为 16 项。

切片 5 的单 Trial 实现及上述真实关卡通过。完整 S1 仍需最小页面/持续调度；实验 HTTP 网关、内存会话预算不满足正式开放条件，未知任务和多租户隔离尚未验收，platform.execution_enabled 继续 false。
