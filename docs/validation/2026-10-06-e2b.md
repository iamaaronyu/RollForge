# 2026-10-06 E2B 与真实 Rollout 验收

## 结论

自托管 E2B 已在局域网 Linux 主机启动。官方 smoke 与两个真实 Harbor + Claude Code + DeepSeek 样例通过；模型、Agent、工具调用和 Verifier 均真实执行。结束后 SDK 查询 Sandbox 数量为 0，宿主 Firecracker 进程数量为 0。

这是受限内存下的基础链路验收，不代表完整 S0 或生产容量验收。六项确定性故障验收也已通过。私密凭证隔离与部署恢复仍需专项验证；Hub 执行入口保持关闭。

- Harbor 0.24.0，独立 Python 3.12 运行环境；E2B Python SDK 2.46.0。
- 官方 Embed Compose 提交：08436994a1c0bd48a7f03a08c020bf7a4a673dfa。
- Claude Code 2.1.81；轨迹元数据确认实际版本。通过官方 npm 包预装，Harbor 校验并复用。
- 模型 API：官方 Anthropic 兼容接口，返回模型名 deepseek-flash。别名可能更新，不是底层权重不可变承诺。
- Ubuntu 22.04、x86_64、内核 6.8.0-138、12 逻辑 CPU、7.57 GiB 内存；部署前 ext4 空闲约 410 GiB。
- 单 Trial 并发，样例 VM 512 MiB、2 vCPU；宿主 HUGEPAGES=1024（2 GiB）。
- local-dev-team 覆盖：最长 24 小时，默认空闲磁盘 2048 MiB；运行脚本仍有超时控制和主动清理。
- 宿主代理只配置下载与 orchestrator，私网 VM 和本地地址直连。Mac 经本机 SSH 隧道访问。

## 确定性故障验收

使用 `examples/run_fault_acceptance.py --run`，在独占测试环境顺序执行。真实 Harbor、E2B 和预装 Claude Code 保持不变；通过任务副本与公开生命周期 Hook 注入指定故障，不修改 Harbor Core。正常 Agent 场景实际调用 DeepSeek；CLI 故障场景在启动时退出，不能作为模型调用成功证据。

| 场景 | 故障注入 | 实测分类 | 原生异常 | 总耗时 | 剩余 Sandbox |
|---|---|---|---|---:|---:|
| 有效零分 | Verifier 正常写入 reward=0 | SCORED | 无 | 8.78 秒 | 0 |
| Verifier 异常 | test.sh exit 42，不写 reward | RUNTIME_FAILED | RewardFileNotFoundError | 4.82 秒 | 0 |
| Verifier 超时 | sleep 120，超时设为 1 秒 | RUNTIME_FAILED | VerifierTimeoutError | 4.94 秒 | 0 |
| Agent 超时 | Agent 执行预算 1 秒 | RUNTIME_FAILED | AgentTimeoutError | 3.18 秒 | 0 |
| Agent 异常 | setup 后将 Sandbox 内 CLI 替换为 exit 42 | RUNTIME_FAILED | NonZeroAgentExitCodeError | 2.40 秒 | 0 |
| 运行中取消 | Verifier 开始 0.5 秒后取消 asyncio Task | RUNTIME_FAILED | CancelledError | 6.83 秒 | 0 |

每个原生 result.json 均通过固定版本 TrialResult 校验；输入内容运行前后摘要一致，输出记录 Manifest。取消异常传播到调用方，Harbor 完成 finally 清理并写入原生结果。当前摘要只有通用 RUNTIME_FAILED，取消的专门业务状态留待 S1 执行模型实现。

Agent 超时与 CLI exit 42 时，Harbor 仍执行 Verifier，得到 reward=0；摘要以 exception_info 为先，正确归为运行失败。只有无异常的零分样本属于 SCORED。这六个样例验证了可控异常和单次协作式取消，不涵盖进程 SIGKILL、宿主重启、重复取消或断网。

## 实测问题与修复

1. 私网 VM 流量错误走代理，导致内部执行 RPC 503；补齐 NO_PROXY 的私网网段和 localhost。
2. 2 GiB VM 的模板快照恢复无法分配大页；在线扩大到 3 GiB 大页池也失败。小样例改为 512 MiB；较大任务仍需增加宿主资源。
3. 失败模板留下 alias，但没有 default 标签；增加 --force-build，使用 Harbor 原生重建参数。
4. Harbor 创建时申请 86400 秒，而本地初始额度只有 1 小时；只覆盖本地测试团队额度。
5. 默认小磁盘无法安装 npm 依赖；设置 2 GiB 默认空闲磁盘，使用 SDK skip_cache=True 重建旧快照。限额修改不扩容已有模板。
6. 原生 Claude 下载域名 TLS 连接失败；官方 npm 包可达，改为模板预装固定版本，保留 Harbor 版本校验。

失败样本均保留原生结果，未归类为零分。部分错误发生在 Agent 运行前，usage 保持 null。失败与成功流程结束后，未发现遗留 Sandbox。
