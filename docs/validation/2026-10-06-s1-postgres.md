# S1 单 Trial 数据库与租约验收

日期：2026-10-06。S0 与 S1 按授权并行推进；本文不代表 S0 或完整 S1 已完成。

## 已实现

- packages/schemas 中的不可变 Revision 引用快照、Job/Trial 查询结构、租约身份与结果提交契约。快照仅允许显式字段，不接受任意环境变量或密钥字段。
- 可回退的 0001_execution 迁移：Job、Trial、Execution 表，外键、唯一约束、状态与 Attempt/token 检查、查询索引。
- PostgreSQL 事务服务：幂等创建、排他领取、续租、幂等完成、过期回收。租约使用数据库时间；状态变化经过共享状态机，执行权校验与写入同事务完成。
- 回收只将 Trial 重新排队；后续领取创建新 Execution，fencing token 递增。Retry 不增加逻辑 Trial 或 Attempt。预算耗尽后终止，不无限重试。
- Manifest 对象键必须属于对应 Job/Trial/Execution；不同 Execution 不能使用同一结果提交路径。

## 真实 PostgreSQL 专项验收

使用本机独立临时 PostgreSQL 16.15 容器（aarch64），无已有数据卷。每项测试创建独立随机 schema，结束仅清理自己的 schema。

8 项测试通过：

1. Alembic 升级、回退、再次升级，以及迁移与 ORM 元数据一致性。
2. 两个独立数据库事务竞争创建和领取，创建幂等、领取仅一个成功，配置或 owner 不同的重复创建拒绝。
3. 已锁定 Trial 的领取跳过，不等待该 Trial 解锁。
4. 并发回收只成功一次；过期和被替换的执行者不能续租、完成或提交失败；Retry 保持原 Trial/Attempt。
5. 无异常零分属于 COMPLETED；错误 Worker 与跨 Execution Manifest 被拒绝；重复完成允许重放，变更结果拒绝。
6. 重建服务连接后任务仍在 PostgreSQL；执行预算耗尽后不能再次领取。
7. 有效续租阻止回收；基础设施失败属于 FAILED。
8. 并发不同结果提交只有一个被接受；同一已接受结果可并发幂等重放。

测试文件：tests/integration/test_execution_postgres.py。另有 6 项领域契约测试，验证禁止额外凭证字段、快照不可变、有限评分与结果语义，以及 Execution 终态不能重开。

带上述数据库运行 make check：66 项测试全部通过，无跳过；Python lint/格式和前端类型/构建通过。make runtime-check：8 项固定版本依赖契约检查通过。

## 复现

在专用 PostgreSQL 测试数据库上设置 ROLLFORGE_TEST_DATABASE_URL，驱动格式为 postgresql+asyncpg。不要将包含真实凭证的连接地址提交或打印。测试账号需要创建与删除自己 schema 的权限。

```sh
make postgres-check
make check
```

postgres-check 未设置地址时明确失败。普通 make check 未设置地址时跳过数据库专项，不能据此声称 PostgreSQL 验收通过。CI 配置了独立 PostgreSQL 服务并运行这些测试；本次本地通过不代表远端 CI 已运行。

## 尚未覆盖

这是数据库执行权验收，两名 Worker 身份由独立事务模拟调用服务，不是已经实现的 Worker 进程验收。服务连接重建不代表 PostgreSQL 服务重启、进程 SIGKILL 或宿主重启验收。

当前快照保存版本引用和执行策略；完整可运行的配置解析将在真实 Worker 接入前补齐。服务尚未验证对象存储中 Manifest 的存在性或摘要，调用方必须在对象上传完成后提交；上传恢复及存储权限仍待后续实现。

用户/Worker 鉴权、业务 API、真实 Runtime 接入、Scheduler 与页面尚未实现；未开放 Hub 执行入口。本次没有调用模型、创建 E2B Sandbox 或修改 Harbor Core，不能算新增主链真实验收。
