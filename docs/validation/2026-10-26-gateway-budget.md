# 模型网关持久请求预算验收记录

日期：2026-10-26。仅验证可信实验网关会话认证与请求次数预算；不代表 TLS、部署认证或正式执行能力已完成。

## 实现

- 网关配置以会话 token 的 SHA-256 作为 key，不将原始会话 token 保存在配置文件。
- 每次接受请求前以 SQLite `BEGIN IMMEDIATE` 原子扣减会话请求额度。账本位于私密配置目录内，文件权限强制为 0600；目录需为 0700。SQLite 事务协调同进程线程和共享同一账本的多个网关进程。
- 配置仍在每次请求时读取，删除会话可立即撤销；账本在网关重启后保留，重复调用不能重置预算。已授权请求会先扣次数，因此上游拒绝与客户端断连也计入请求次数。
- 预算按请求数计算，不等同于 token、成本或模型费用预算。HTTP 无传输加密；该网关仍仅适用于隔离实验网络。
